Live online game
🏠 Classic Board The full board game with real multiplayer. One person creates a room and shares the code — everyone else joins on their own phone, picks their own name + character, and anyone can start the game. 🎴 Cards Mode The fast card version — jump straight in solo against the computer, or create a room in the lobby and play a Cards match with the whole family.

👨‍👩‍👧‍👦 How family multiplayer works

  1. One person taps Classic Board and creates a room.
  2. Share the 4-letter room code with the family.
  3. Everyone opens 1poly, joins with the code, then picks their own name + character token and taps Join Game.
  4. Anyone in the game taps START — no waiting on the host. Phones stay in sync, so if yours refreshes, you're still in.

☕ First load can take about 30 seconds while the game server wakes up — that's normal. 1poly needs internet; the rest of KidHub works offline.
