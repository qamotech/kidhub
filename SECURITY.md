# 🔐 Security notes

This repository contains a static application, not a secure account or communication service. Browser local storage is accessible to scripts running on the same origin. Parent controls are not an authentication boundary.

Do not publish credentials, personal data, or sensitive image samples in reports. Use the repository's private vulnerability reporting option if available; otherwise contact the owner through an existing private channel before disclosing exploit details. No response-time or support guarantee is stated.

When deploying, review external resource requests, hosting settings, and applicable organizational requirements. The Art Studio changes have functional regression coverage, not a comprehensive security audit.
